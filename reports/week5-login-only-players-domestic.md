## 五、结论

1. **主体是「浅尝辄止」玩家，而非「高练度拒战党」** —— 67.6% 等级个位数、整体中位数 Lv.1，大部分是注册后基本没玩下去的号（新号/弃号/小号），战斗玩法转化对这批人不是首要问题
2. **付费与练度强绑定**：付费档位每升一档，等级中位数跳一截（1 → 57 → 123 → 149 → 162 → 198），说明未战斗的付费玩家确实在认真养成
3. **🎯 最值得关注：3,629 名「付费 + 中高练度 + 四种战斗玩法全零参与」玩家** —— 4.7% 的人贡献 67.4 万累计流水，等级中位 57~198，是纯粹的收集/养成/PVE 向玩家。相比拉新，针对这批人做战斗玩法转化（新手引导优化、战斗入口推送、段位保护机制）ROI 更高

## 附：数据文件与复现方法

**数据文件**（`data/domestic/archive/` 下，均不进 git）：

| 文件 | 说明 |
|---|---|
| `week5/login_week5.csv` | Week5 登录事件（99 万行） |
| `week5/ladder_week5.csv` / `tournament_week5.csv` / `guild_war_week5.csv` | 三种 PVP 战斗事件 |
| `gym_infinity.csv` | 无限道馆累计明细（按 part_date 过滤 Week5 得 15,607 人） |
| `week5/levels_week5.csv` | 数数拉取：Week5 `MAX(b_level)`（2.22 MB） |
| `week5/recharge_upto_week5.csv` | 数数拉取：截至 08-13 累计充值（0.98 MB） |
| `week5/only_login_ids.json` | 仅登录未战斗的 b_role_id 集合（76,929 个，含道馆排除口径） |

**等级拉取 SQL**（数数开放 API，format=csv）：

```sql
SELECT b_role_id, MAX(TRY_CAST(b_level AS bigint)) AS level
FROM ta.v_event_29
WHERE "$part_date" >= '2026-08-07' AND "$part_date" <= '2026-08-13'
  AND "#event_name" = 'player_login'
  AND TRY_CAST(b_zone_id AS bigint) IN (1888)
GROUP BY b_role_id
```

**充值拉取**（现成命令）：

```bash
node scripts/ta-fetch.mjs --region domestic --mode recharge \
  --start 2026-01-01 --end 2026-08-13 \
  --out data/domestic/archive/week5/recharge_upto_week5.csv
```

**集合运算**：`only_login = login − (ladder ∪ tournament ∪ guild_war ∪ gym[Week5日期过滤])`

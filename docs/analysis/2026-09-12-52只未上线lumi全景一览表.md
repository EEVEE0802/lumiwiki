## 七、v2 关键澄清

### 7.1 独立被动 vs 家族共享的判定
- **BP + InbornBP 用户数 ≤ 2** = 独立被动 → 详细分析
- **BP + InbornBP 用户数 ≥ 4** = 家族大共享 → 跳过，归入关键字/家族综述
- **BP + InbornBP 用户数 2-3** = 家族梯度 → 只分析家族终形态

### 7.2 3 个"曾经的 P0"实际是家族共享 → 需要重新审视
- **147801 南瓜莱姆 Piercing=7500**：**是 [[glossary]] Id 25 史莱姆之力·超能属性** 的既定机制，跟 105301 史莱姆王家族 9 只共享（原 P0"服务端最高数值"警报 → 已纠正为家族既定）
- **蜜桃/灰灰家族 10 只**：全部挂 `11000901` 共享先天被动，属家族关键字机制

### 7.3 双向 combo 新发现
- **120902 荆棘盛放 + 111201 森灵龙**（**现役 T1**！）：森灵龙敌方登场即 +2 寄生 → 荆棘盛放被动同步 +2 攻/疾速 → 主动技吃干爆发
- **111204 森灵龙·异 + 120902 荆棘盛放**：跟原版一样的机制但异色（可能强度稍强）
- **1003501 小红帽 + 1003601 大灰狼**：大灰狼消耗小红帽血量爆发（家族大共享里的独立 combo）
